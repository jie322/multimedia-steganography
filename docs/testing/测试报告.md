# 多媒体隐写系统测试报告

本次上传前于 2026 年 11 月 15 日，在 Windows 和新建的 Python 3.12 虚拟环境中复核项目。算法与 HTTP 接口检查共 75 项，浏览器流程检查共 10 项，全部通过。

## 测试素材

测试使用 `test_resources/downloads/` 中的 JPG 和 MP4。图片约 250 万像素，原视频约 3 分半、23MB。WAV 音轨、短音频及约 130KB 的 5 秒短视频均由该视频制作。

## 复核结果

| 检查内容 | 结果 |
| --- | --- |
| JPG、PNG、BMP、RGBA 与灰度图像处理 | 载荷能够完整恢复，输出为 PNG |
| 图片和 WAV 隐藏中文文本、二进制、图片、音频及短视频 | 恢复内容与原件一致，保留文件名和文本标识 |
| 1 至 8 位 LSB 文本嵌入与恢复 | 通过 |
| 8、16、24、32 位 PCM WAV | 能够恢复，音频格式参数保持 |
| 容量计算与边界检查 | 恰好达到容量时能够恢复，超限输入被拒绝 |
| 原始 MP4 作为载荷 | 约 23MB，超过测试载体容量，在写入前拒绝 |
| 旧载荷兼容与 WAV 手动长度恢复 | 通过 |
| 空内容、缺少载体、错误位数与截断媒体 | 返回相应错误信息 |
| 网页上传、拖拽、生成、提取与下载 | 通过 |
| WAV 播放、低位可视化、手机布局与主题保持 | 通过 |
| 浏览器未捕获脚本错误 | 未发现 |

2 位 LSB 下，测试图片可用容量约 1.9MB，20 秒 WAV 约 480KB，两者都能容纳约 130KB 的短视频。恢复准确性通过内容比较验证；相关失真指标仅描述本次素材和载荷，不代表所有图片或音频。

## 复现方式

安装项目依赖后，在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe .\test\run_project_tests.py
```

浏览器流程检查需要先启动 Web 服务并准备 Playwright 浏览器，步骤见根目录 README，然后执行：

```powershell
node .\test\browser_smoke.js
```

算法与接口脚本自行选择临时端口。本次浏览器复核使用独立的本地服务端口，脚本默认连接 9001；可通过 `STEGO_BASE_URL` 指定服务地址。

本目录的 `test_results.json` 和 `browser_results.json` 保存本次机器可读记录。浏览器记录中的文件路径转换为项目相对路径，检查结果保持不变。每次本地执行的新结果写入 `output/testing/`。

## 适用范围

系统以图片和 WAV 作为载体，MP4 仅作为待隐藏文件。图像低位可视化不提供自动隐写判定，普通 LSB 不提供加密或抗统计检测能力。重新压缩、转码和编辑可能破坏已嵌入的数据。
